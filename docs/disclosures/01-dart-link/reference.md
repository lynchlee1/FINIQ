# KIND·DART 식별자 연결

## 기능 범위

- KIND와 OpenDART 식별자를 연결할 때 지켜야 할 규칙을 설명한다.

## 자료 흐름

- 아직 구현하지 않았다.
- KIND에는 기업 구분용 키 `company_id`와 문서 구분용 키 `acpt_no`, `doc_no`가 존재한다.
- DART에는 기업 구분용 키 `corp_code`, `stock_code`와 문서 구분용 키 `rcept_no`가 존재한다.
- 이 식별자는 모두 로마자를 포함할 수 있는 텍스트다. 숫자라고 가정하지 않는다.

## 처리 계약

### 중단 조건

#### 연결에 실패하면 중단

불확실한 연결을 만들지 않는다.
- 기업 후보를 하나로 확정하지 못했을 때 실패 처리한다.
- 공시 후보를 하나로 확정하지 못했을 때 실패 처리한다.
