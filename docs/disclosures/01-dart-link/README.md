### **1. Summary**

#### **기능 요약**
- KIND와 OpenDART의 식별자를 구분하고 공시 연결을 다시 구현할 때 지켜야 할 규칙을 설명한다.

#### **세부 설명**
- 아직 구현되지 않은 기능이다.
- KIND에는 기업 구분용 키 `company_id`와 문서 구분용 키 `acpt_no`, `doc_no`가 존재한다.
- DART에는 기업 구분용 키 `corp_code`, `stock_code`와 문서 구분용 키 `rcept_no`가 존재한다.
- 위에 언급된 키들은 모두 로마자를 포함할 수 있는 텍스트다. 숫자를 가정하지 않는다.
