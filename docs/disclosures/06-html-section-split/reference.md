# 목차 HTML 저장 Reference

## 경로와 형식

- 입력 경로는 `<data_root>/05-internal-html-download/<mode>`, 저장 경로는 `<data_root>/06-sections`이며 저장 형식은 아래와 같다.
- HTML은 연도별 폴더에 저장하며 parser JSON은 만들지 않는다.

```text
<data_root>/
├── 05-internal-html-download/
│   └── <mode>/<year>/<acpt_no>.html
└── 06-sections/
    └── <year>/<acpt_no>.html
```
