# 목차 HTML 저장

## 목적

- KIND 본문에서 목차를 골라 해당 범위를 HTML로 저장한다.

공시 자동화 06단계에서 저장할 목차를 확인하고 본문 범위를 나눈다.

## 핵심 기능

### 목차 HTML 분리

KIND 본문에 있는 목차 경계와 문서 구조를 보존한 HTML을 만든다.

## 사용과 화면

### 목차 선택

사용자가 저장할 목차를 직접 고른다.

- 사용자는 체크박스, 전체 선택 또는 전체 해제로 저장 범위를 정한다.

### 목차 분리 표시 범위 제한

분리 결과를 바꾸지 않고 화면에 전달할 진행 내역만 제한한다.

## 작업 안내

### 처음 보는 목차 검토하기

06단계가 저장 규칙이 없는 목차를 찾아 `needs_review`로 멈췄을 때 이 절차를 따른다.

1. 공시 자동화 화면에 있는 `목차 조합 모아보기`에서 처음 보는 목차 조합을 확인한다.
2. 저장할 목차를 체크박스로 고른다. 조합 안에 있는 목차를 모두 고르거나 빼려면 `전체 선택`과 `전체 해제`를 사용한다.
3. 모든 조합에서 저장할 목차를 골랐는지 확인한다. 저장할 목차가 없는 조합도 `전체 해제`로 판단을 남겨야 한다.
4. `후속 실행`을 누르고 다음 단계가 시작되는지 확인한다.
