# 01단계 결과 다시 받기

기존 KIND 조건검색 결과가 무결성 검사를 통과하지 못했고, 기존 결과를 지운 뒤 전체 기간을 다시 받아야 할 때 이 절차를 따른다.

1. 공시 자동화 화면 오른쪽 `알림`에서 어느 기간의 결과가 어떤 검사에서 어긋났는지 확인한다. 저장한 페이지 수와 현재 KIND 페이지 수가 다르면 두 값도 함께 보여 준다.
2. 기존 결과를 지우고 해당 기간을 처음부터 다시 받아도 되는지 판단한다.
3. 다시 받으려면 `전체 다시 받기`를 누른다. 기존 결과를 유지하려면 누르지 않는다.
4. 작업이 끝나면 01단계 상태가 `완료`로 바뀌었는지 확인한다. 실행 중 검색 조건이나 충돌 내역이 바뀌면 화면은 다시 확인을 요청한다.

`전체 다시 받기`를 누르지 않으면 기존 결과를 지우거나 다시 받지 않는다. 서버가 확인값을 검사하는 방법과 중단 조건은 [KIND 조건검색 결과 저장](reference.md)에서 확인한다.
