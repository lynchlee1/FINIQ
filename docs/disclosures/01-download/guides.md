# KIND 조건검색 결과 저장

## 목적

- KIND 공시 조건검색 결과를 HTML로 저장한다.

공시 자동화 01단계에서 검색 조건을 정하고 실행한다.

## 핵심 기능

### 기존 데이터 무결성 검사

자료를 최신으로 유지하려고 연도별 폴더에서 무결성을 검사한다.

- 기존 데이터 무결성 확인은 다운로드의 선행 조건이다.

### metadata 만들기

자료 무결성을 검사하고 복원할 수 있도록 metadata를 만든다.

### 다운로드 목록 일관성 확인

한 검색기간의 결과가 같은 시점의 KIND 목록으로 구성됐는지 게시 전에 확인한다.

## 사용과 화면

### 다운로드 실행 기본값

생략 가능한 요청값을 정상 계약에 정의된 값으로 채운다.

- 회사명은 `""`, 제출인은 `""`, 시장은 `전체`, 증권 종류는 `전체`로 채운다.

### 누락 페이지 표시 범위 제한

전체 누락 결과를 바꾸지 않고 화면에 전달할 범위만 제한한다.

### 진행 내역 전달·보관 범위 제한

다운로드 결과와 관계없는 진행 내역의 화면 전달 범위를 정한다.

- 직접 실행의 진행 내역 전달 기간은 실행 중으로 한정한다.

- 백그라운드 작업은 정해진 줄 수만큼 최근 내역을 보관한다.

## 작업 안내

### 01단계 결과 다시 받기

기존 KIND 조건검색 결과가 무결성 검사를 통과하지 못했고 기존 결과를 지운 뒤 전체 기간을 다시 받아야 할 때 이 절차를 따른다.

1. 공시 자동화 화면 오른쪽 `알림`에서 어느 기간의 결과가 어떤 검사에서 어긋났는지 확인한다.
2. 기존 결과를 지우고 해당 기간을 처음부터 다시 받아도 되는지 판단한다.
3. 다시 받으려면 `전체 다시 받기`를 누른다. 기존 결과를 유지하려면 누르지 않는다.
4. 작업이 끝나면 01단계 상태가 `완료`로 바뀌었는지 확인한다.
