# 연도별 SQLite 변환

## 목적

HTML로 저장한 KIND 조건검색 결과를 검색 가능한 연도별 SQLite 조각으로 바꾼다.

## 핵심 기능

### KIND 결과표 읽기

01단계 HTML에서 공시 결과표를 읽어 SQLite에 저장할 공시 행을 만든다.

### 연도별 SQLite 만들기

공시일에서 연도를 읽어 `<YYYY>.sqlite` 조각을 만든다.

### 중복 공시 정리

공시 행을 중복 없이 SQLite에 저장한다.

### 회사 표시 정보 추출

회사 칸에서 시장과 badge를 읽어 공시 행의 표시 정보로 저장한다.

### 변환 근거 기록

SQLite 조각마다 원본과 변환 결과를 manifest에 기록한다.

### 결과 무결성 검사

입력 행이 저장이나 중복 집계에서 빠지지 않았는지 검증한다.

## 사용

공시 자동화 02단계를 실행하면 01단계 HTML을 위 순서로 변환한다.
