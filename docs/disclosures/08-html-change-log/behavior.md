# 정정내역 비교 정상 동작

기본 자료 흐름과 정상 실행 계약을 설명한다.

## 자료 흐름

- 입력 경로는 `<data_root>/07-converted/<mode>/parsed-<mode>.json`이다.
- 08단계는 조회 화면이며 별도의 `08-*` 폴더나 결과 JSON을 만들지 않는다.

```text
<data_root>/
└── 07-converted/
    └── <mode>/
        └── parsed-<mode>.json
```

## 처리 계약

### 정상 동작

#### 정정 family 선택

비교 가능한 정정 family의 범위를 확정한다.
- family ID가 있고 문서 순서가 정수이며 문서가 2개 이상인 결과만 선택한다.
- family ID가 큰 순서로 정렬한다.

#### 문서별 변동 비교

최초 공시부터 최신 정정공시까지 이웃한 문서의 값 변화를 계산한다.
- family 안의 문서는 공시 순서와 접수번호로 정렬한다.
- 이웃한 두 문서에 저장된 비교 항목을 그대로 비교한다.
- 변경 전후 값과 변경 항목을 비교 결과에 유지한다.

#### 변동 임계값

날짜나 수치의 작은 차이를 주요 변동 집계에서 제외한다.
- 날짜 차이는 설정한 일수 이하, 수치 차이는 설정한 비율 이하이면 작은 변동으로 본다.
- 목록은 구조와 순서가 같고 모든 수치 차이가 기준 이하일 때만 작은 변동으로 본다.
- `회차`의 변경은 주요 변동으로 집계하지 않는다.

#### 조회 필터와 내보내기

조건에 맞는 family와 Excel 행을 선택한다.
- 제목, 접수번호, 항목 이름으로 검색한다.
- `변경사항만 보기`는 주요 변경이 있는 family만 결과에 포함한다.
- `최신버전만`을 선택하면 family마다 최신 문서만 Excel에 넣는다.

## 화면과 서비스 계약

### 정상 동작

#### 정정내역 조회 요청

화면에서 비교 범위와 표시 조건을 비교 요청으로 전달한다.
- 사용자는 `변동 임계값`에서 날짜와 수치 기준을 저장한다.
- 결과 폴더, 변환 유형과 조회 개수를 요청값으로 사용한다.
- 변동 임계값을 지정하지 않으면 날짜는 3일, 수치는 1%를 비교 입력으로 사용한다.

#### 정정 family 목록 표시

정정 이력이 있는 공시를 빠르게 찾는다.
- 비교 결과에 포함한 family 가운데 화면에서 정한 개수만 보여 준다.
- 처음에는 문서 수, 제목과 바뀐 항목만 보여 주고 family를 선택하면 상세 내용을 불러온다.
- 바뀐 항목 이름 일부와 나머지 개수를 보여 준다.

#### 정정내역 표 표시

비교 작업이 만든 변경 결과만 화면에 표시한다.
- 상세 화면은 문서 정보와 변경 전후 값을 함께 보여 주며 바뀐 항목은 행, 공시 순서는 열로 표시한다.
- 요청한 항목과 관계없는 내용은 제외한다.
- 발행금액과 발행가액은 숫자일 때 억 원 단위로 보여 준다.
- 목록은 쉼표로 잇고 빈 값은 `-`로 표시한다.
