# 정정내역 비교 Cases

## 처리 계약

### 한계

#### 정정내역 값 판정

날짜와 수치를 확실히 읽을 수 있을 때만 작은 변동인지 판정한다.
- 날짜는 한글 날짜, 점이나 하이픈 한 가지로 나눈 날짜 또는 `YYYYMMDD` 형식만 읽는다. 실제로 없는 날짜는 읽지 않는다.
- 수치는 부호, 숫자 올바른 쉼표와 소수점만 있을 때 읽는다. 목록과 묶음 안의 수치도 같은 기준으로 읽고 순서는 바꾸지 않는다.
- 날짜나 수치를 읽지 못하면 작은 변동에서 제외하지 않는다.

### 중단 조건

#### 변환 결과 입력 오류가 나면 중단

비교할 변환 유형과 결과 파일이 분명하지 않으면 비교를 실행하지 않는다.
- 변환 결과 파일이 없거나 읽을 수 없으면 실패 처리한다.

## 화면과 서비스 계약

### 복구 동작

#### 정정내역 표시 복구

일부 표시값을 만들지 못해도 확인된 변경 결과는 계속 보여 준다.
- 변경 기록이 없거나 문서 위치를 찾지 못한 칸은 비워 둔다.
- 발행금액이나 발행가액이 숫자가 아니면 원래 값을 보여 준다.
- 발행대상자나 투자자 금액을 읽지 못하면 각 항목을 공백으로 이어 표시한다.

### 중단 조건

#### 조회 요청 오류가 나면 중단

비교 범위를 임의로 바꿔 실행하지 않는다.
- 결과 폴더나 변환 유형이 없으면 실패 처리한다.
- 지원하지 않는 변환 유형, 잘못된 폴더와 1보다 작은 조회 개수는 실패 처리한다.

## 조건부 동작

### 변동 임계값

- 날짜 차이는 설정한 일수 이하, 수치 차이는 설정한 비율 이하이면 작은 변동으로 본다.

- 목록은 구조와 순서가 같고 모든 수치 차이가 기준 이하일 때만 작은 변동으로 본다.

- `회차`의 변경은 주요 변동으로 집계하지 않는다.

### 조회 필터와 내보내기

- `최신버전만`을 선택하면 family마다 최신 문서만 Excel에 넣는다.

### 정정내역 조회 요청

- 변동 임계값을 지정하지 않으면 날짜는 3일, 수치는 1%를 비교 입력으로 사용한다.

### 정정 family 목록 표시

- 처음에는 문서 수, 제목과 바뀐 항목만 보여 주고 family를 선택하면 상세 내용을 불러온다.

### 정정내역 표 표시

- 발행금액과 발행가액은 숫자일 때 억 원 단위로 보여 준다.

- 요청한 항목과 관계없는 내용은 제외한다.
