# 공시 관계 그래프 Cases

## 처리 계약

### 복구 동작

#### 식별값 누락 공시 제외

node와 edge를 식별할 수 없는 공시는 제외하고 나머지 입력으로 그래프를 계속 만든다.
- 파싱 결과에 `acpt_no`가 없거나 필터 결과에서 회사 식별값을 만들 수 없으면 해당 공시를 제외한다.
- 제외 건수와 회사 식별값 누락 건수는 graph metadata에 기록한다.

#### 발행사 이름 대체

기본 발행사 이름이 비어 있으면 정해 둔 다른 출처에서 이름을 읽고 그래프를 계속 만든다.
- 회사명이 비어 있으면 변환 유형별 파싱 결과에서 발행사를 먼저 찾고 없으면 필터 결과에서 회사명과 제출인을 차례로 찾는다.

#### 취득 관계 축소 연결

증권 node를 만들지 못한 유무상증자 결과도 발행 event까지 연결해 보존한다.
- 유무상증자 결과에 증권 node가 없으면 투자자 `ACQUIRED` edge를 발행 event에 연결한다.

#### edge 가중치 대체

edge 가중치가 빠졌으면 미리 정한 중립값으로 저장한다.
- edge 가중치가 없으면 `0.0`을 저장한다.

### 중단 조건

#### 입력 계약 오류가 나면 중단

그래프에 필요한 입력 파일 쌍과 JSON을 확정하지 못하면 작업을 실행하지 않는다.
- 지원하는 mode에서 필터 결과와 파싱 결과 중 하나만 있으면 누락 파일을 표시하고 실패 처리한다.
- 완전한 입력 쌍이 하나도 없으면 실패 처리한다.
- 입력 JSON을 읽을 수 없으면 실패 처리한다.

#### event 날짜를 확정하지 못하면 중단

그래프 node와 edge에 기록할 날짜를 만들 수 없으면 불완전한 결과를 저장하지 않는다.
- 공시일이나 허용된 대체 날짜를 지원 형식으로 변환할 수 없으면 실패 처리한다.
- event 날짜를 확정하지 못하면 그래프를 만들지 않는다.

## 화면과 서비스 계약

### 중단 조건

#### 작업공간 요청 오류가 나면 중단

그래프 입력이나 저장 결과가 있는 작업공간을 임의로 추측하지 않는다.
- `작업공간 디렉토리`가 없거나 실제 디렉토리가 아니면 실행 요청을 실패 처리한다.

#### 저장 결과 오류가 나면 중단

- 저장 파일이 없거나 JSON으로 읽을 수 없으면 실패 처리한다.
- 저장 형식과 metadata가 현재 규칙과 다르거나 node·edge 목록을 읽을 수 없으면 실패 처리한다.
- 저장 입력을 확정하지 못하면 화면 결과를 만들지 않는다.

## 조건부 동작

### 투자자 node 분류

- 투자자 이름이 수집한 회사와 일치하지 않으면 이름 표기를 기준으로 Person, Company 또는 Organization node를 만든다.

### 그래프 입력 mode 선택

- 두 결과가 모두 없는 mode는 입력에서 제외한다.

### 그래프 만들기·저장

- 같은 회사명이나 투자자명은 builder에 정한 entity resolution 규칙으로 합친다. 동명이인은 발행사마다 서로 다른 person node로 유지한다.

- 임시 파일에 전체 JSON을 쓴 뒤 최종 경로로 교체하므로 완료되지 않은 파일을 정상 결과로 노출하지 않는다.

### 그래프 탐색 표시

- 탐색 상태는 화면 입력이며 저장된 node와 edge를 바꾸지 않는다.

### node 표시명 선택

- 이 선택은 화면에 보일 문자열만 정하며 저장한 node 속성은 바꾸지 않는다.
