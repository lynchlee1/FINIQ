### **1. Summary**

#### **기능 요약**
- 유상증자 공시에서 자금 사용처, 발행가액, 방식, 일정과 발행대상자를 추출하는 규칙이다.

#### **세부 설명**
- 표 선택, 주식 종류, 상태와 합계 검증은 [유무상증자 공통 규칙](../README.md)을 따른다.
- 현재 문서는 외부 제목에서 `유상증자`를 확인한 공시에만 적용한다.

### **2. Core**

#### **Feature**

**[Core Processing] 발행목적 추출 기능**
- **목적:** 표에 적힌 자금 사용처와 금액을 그대로 저장한다.
- `N=1`이 `자금조달의 목적`과 정확히 일치하는 모든 행에서 `N=2`의 사용처명과 맨 오른쪽 금액을 HTML 순서대로 읽는다.
- 사용처명에서는 원 단위 표기만 제거하며 허용 이름이나 탐색 순서를 하드코딩하지 않는다.
- 0이나 `-`인 항목은 제외한다. 숫자를 하나도 읽지 못하면 `null`과 `source_not_found`, 숫자는 있지만 양수 항목이 없으면 빈 목록과 `explicit_zero`를 기록한다.
<br>

**[Core Processing] 발행가액 추출 기능**
- **목적:** 설명과 예정일을 제외하고 종류별 확정 발행가액을 저장한다.
- 일반 양식은 `N=1`이 `신주 발행가액`, `N=2`가 주식 종류인 첫 행의 맨 오른쪽 값을 읽는다.
- 예정·확정 양식은 `N=1`이 `신주 발행가액`, `N=2`가 `확정발행가`, `N=3`이 주식 종류인 첫 행의 맨 오른쪽 값을 읽는다.
- `N=2`가 `예정발행가`인 행은 맨 오른쪽이 확정예정일이므로 사용하지 않는다.
- 보통주식·기타주식 두 항목을 항상 유지한다.
- 첫 일치 행의 0이나 `-`를 뒤 행의 양수로 바꾸지 않으며, 숫자를 읽지 못한 종류는 `null`이다.
<br>

**[Core Processing] 증자방식 추출 기능**
- **목적:** 유상증자 방식을 정해진 이름에서 읽는다.
- `N=1`이 `증자방식`과 정확히 일치하는 첫 행의 맨 오른쪽 값을 읽는다.
<br>

**[Core Processing] 납입일 추출 기능**
- **목적:** 유상증자 납입일을 정해진 이름에서 읽는다.
- `N=1`이 `납입일`과 정확히 일치하는 첫 행의 맨 오른쪽 값을 읽는다.
<br>

**[Core Processing] 신주배정기준일 추출 기능**
- **목적:** 유상증자 배정기준일을 정해진 이름에서 읽는다.
- `N=1`이 `신주배정기준일`과 정확히 일치하는 첫 행의 맨 오른쪽 값을 읽어 유상 상세에 저장한다.
<br>

**[Core Processing] 1주당 신주배정주식수 추출 기능**
- **목적:** 유상증자의 주당 배정수를 정해진 이름에서 읽는다.
- `N=1`이 `1주당 신주배정주식수 (주)` 또는 `1주당 신주배정주식수`와 정확히 일치하는 첫 행의 맨 오른쪽 값을 읽는다.
- `N=2`에 주식 종류가 있는 양식은 종류별 값을 저장하고, 두 칸 양식은 보통주식 값으로 저장한다.
<br>

**[Core Processing] 신주권교부예정일 추출 기능**
- **목적:** 유상증자 신주권 교부예정일을 정해진 이름에서 읽는다.
- `N=1`이 `신주권교부예정일`과 정확히 일치하는 첫 행의 맨 오른쪽 값을 읽는다.
<br>

**[Core Processing] 상장예정일 추출 기능**
- **목적:** 유상증자 신주의 상장예정일을 정해진 이름에서 읽는다.
- `N=1`이 `신주의 상장 예정일`과 공백을 제외하고 정확히 일치하는 첫 행의 맨 오른쪽 값을 읽는다.
<br>

**[Core Processing] 유상 상세 생성 기능**
- **목적:** 유상증자에 적용되는 값을 `유상증자`에 모아 저장한다.
- 최상위 수량·목적·가액·방식·납입일·일정·발행대상자를 그대로 사용한다.
- `신주배정기준일`과 `1주당 신주배정주식수`는 위의 고정 N 규칙으로 유상증자 부분에서 따로 읽는다.
- `무상증자`는 `null`로 저장한다.
