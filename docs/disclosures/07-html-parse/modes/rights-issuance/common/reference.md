# 유무상증자 공통 변환 Reference

## 적용 범위

- HTML·metadata·상태·warning·최종 payload의 공통 계약은 [공시원문 변환 사양](../../../common/reference.md)을 따른다.
- 유형별 차이는 [유상증자](../paid/reference.md), [무상증자](../bonus/reference.md), [유무상증자 혼합 변환](../mixed/reference.md)에서 설명한다.

## 결과 형식

- `신주의 종류와 수`와 `증자 전 발행주식총수`는 보통주식·기타주식 항목을 항상 유지한다.
