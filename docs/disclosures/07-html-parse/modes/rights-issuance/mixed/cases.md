# 유무상증자 혼합 변환 Cases

## 처리 계약

### 중단 조건

#### 무상증자 section이 누락되면 중단

유상과 무상 값을 나눌 수 없는 원문에서 혼합 결과를 만들지 않는다.
- 외부 제목이 유무상증자인데 무상증자 구분점을 찾지 못하면 실패 처리한다.

## 조건부 동작

### 상세값 누락

- 유상·무상 각 부분의 값이 누락돼도 선택하지 않은 표나 최상위 값으로 채우지 않는다.
- 무상 상세값이 누락돼도 최상위 값이나 유상 상세값으로 채우지 않는다.

### 유상·무상 section 분리

- 합친 줄에서 앞 번호와 공백을 제거한 `N=1`이 `무상증자`와 정확히 일치하는 첫 한 칸짜리 행을 구분점으로 사용한다. 앞 번호가 없는 `무상증자`도 같은 구분점이다.
