### **1. Summary**

#### **기능 요약**
- 유무상증자 공시의 유상 부분과 무상 부분을 나누어 두 상세 결과를 만드는 규칙이다.

#### **세부 설명**
- 표 선택, 주식 종류, 상태와 합계 검증은 [유무상증자 공통 규칙](../README.md)을 따른다.
- 유상 부분의 값은 [유상증자 규칙](../paid/README.md), 무상 부분의 값은 [무상증자 규칙](../bonus/README.md)을 따른다.

### **2. Core**

#### **Feature**

**[Core Processing] 유상·무상 section 분리 기능**
- **목적:** 하나의 공시에 함께 있는 유상과 무상 값을 구분한다.
- 합친 줄에서 앞 번호와 공백을 제거한 `N=1`이 `무상증자`와 정확히 일치하는 첫 한 칸짜리 행을 구분점으로 사용한다. 앞 번호가 없는 `무상증자`도 같은 구분점이다.
- 구분점 앞은 유상 부분, 뒤는 무상 부분으로 처리한다.
- 선택하지 않은 표나 최상위 값으로 각 부분의 누락값을 채우지 않는다.
<br>

**[Core Processing] 유상 상세 생성 기능**
- **목적:** 최상위 유상 값을 `유상증자`에 함께 저장한다.
- 최상위 수량·목적·가액·방식·납입일·일정·발행대상자를 사용한다.
- `신주배정기준일`과 `1주당 신주배정주식수`는 유상 부분에서 따로 읽는다.
<br>

**[Core Processing] 무상 상세 생성 기능**
- **목적:** 무상 부분에 적힌 값만 `무상증자`에 저장한다.
- 수량, 증자 전 수량, 배정기준일, 1주당 배정수, 교부예정일과 상장예정일을 무상 부분에서 다시 읽는다.
- 최상위 또는 유상 상세값으로 무상 상세의 누락값을 채우지 않는다.
<br>

#### **Fallback**

- 없음.

#### **Shutdown**

**[Core Processing] 무상증자 section 누락시 중단하기**
- **목적:** 유상과 무상 값을 나눌 수 없는 원문에서 혼합 결과를 만들지 않는다.
- 외부 제목이 유무상증자인데 무상증자 구분점을 찾지 못하면 실패 처리한다.

그 밖의 중단 규칙은 [유무상증자의 Core Shutdown](../README.md#shutdown)을 따른다.
