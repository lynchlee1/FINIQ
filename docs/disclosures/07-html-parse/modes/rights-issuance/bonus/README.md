### **1. Summary**

#### **기능 요약**
- 무상증자 공시에서 적용하지 않는 값과 무상 배정 수량·일정을 구분해 저장하는 규칙이다.

#### **세부 설명**
- 표 선택, 주식 종류와 상태는 [유무상증자 공통 규칙](../README.md)을 따른다.
- 현재 문서는 외부 제목에서 `무상증자`를 확인한 공시에만 적용한다.

### **2. Core**

#### **Feature**

**[Core Processing] 무상증자 적용 제외 기능**
- **목적:** 무상증자에 없는 유상증자 항목을 검색 결과 누락과 구분한다.
- `발행목적`, `발행가액`, `증자방식`, `납입일`, `발행대상자`는 검색하지 않는다.
- 각 값에는 `-`, 상태에는 `not_applicable`을 기록하며 warning과 합계 검증에서 제외한다.
<br>

**[Core Processing] 신주배정기준일 추출 기능**
- **목적:** 무상증자 배정기준일을 정해진 이름에서 읽는다.
- `N=1`이 `신주배정기준일`과 정확히 일치하는 첫 행의 맨 오른쪽 값을 읽는다.
<br>

**[Core Processing] 1주당 신주배정주식수 추출 기능**
- **목적:** 무상증자의 주당 배정수를 정해진 이름에서 읽는다.
- `N=1`이 `1주당 신주배정주식수 (주)` 또는 `1주당 신주배정주식수`와 정확히 일치하는 첫 행의 맨 오른쪽 값을 읽는다.
- `N=2`에 주식 종류가 있는 양식은 종류별 값을 저장하고, 두 칸 양식은 보통주식 값으로 저장한다.
<br>

**[Core Processing] 신주권교부예정일 추출 기능**
- **목적:** 무상증자 신주권 교부예정일을 정해진 이름에서 읽는다.
- `N=1`이 `신주권교부예정일`과 정확히 일치하는 첫 행의 맨 오른쪽 값을 읽어 최상위와 무상 상세에 저장한다.
<br>

**[Core Processing] 상장예정일 추출 기능**
- **목적:** 무상증자 신주의 상장예정일을 정해진 이름에서 읽는다.
- `N=1`이 `신주의 상장 예정일`과 공백을 제외하고 정확히 일치하는 첫 행의 맨 오른쪽 값을 읽어 최상위와 무상 상세에 저장한다.
<br>

**[Core Processing] 무상 상세 생성 기능**
- **목적:** 무상증자에 적용되는 값을 `무상증자`에 모아 저장한다.
- `신주의 종류와 수`, `증자 전 발행주식총수`, `신주배정기준일`, `1주당 신주배정주식수`, `신주권교부예정일`, `상장예정일`을 각 필드의 고정 N 규칙으로 무상증자 부분에서 읽는다.
- 최상위 값으로 상세 결과의 누락값을 채우지 않는다.
- `유상증자`는 `null`로 저장한다.
