# 기존 HTML을 확인하고 기준 해시 만들기

기존 외부 HTML이나 본문 HTML에 바이트 수와 SHA-256 기준값이 없어 작업이 멈췄을 때 이 절차를 따른다.

1. 멈춘 단계가 외부 HTML 저장인지 본문 HTML 저장인지 확인한다.
2. 현재 HTML이 믿을 수 있는 원본인지 직접 확인한다.
3. 외부 HTML이면 `현재 외부 HTML 신뢰`, 본문 HTML이면 `현재 내부 HTML 신뢰` 체크박스를 고른다.
4. `기준 해시 생성`을 누르고 작업이 끝날 때까지 기다린다.
5. 작업이 끝나 화면에 저장 범위가 다시 표시되면 `기준 없음`이 0건이고 `해시 확인`이 기존 HTML 건수와 같은지 확인한다.
6. 다운로드 `실행`을 눌러 나머지 작업을 잇는다. 현재 파일이 기준 해시와 다르면 해당 파일은 다시 받는다.

파일을 직접 확인하지 않았다면 기준 해시를 만들지 않는다. 파일 크기나 SHA-256이 기준값과 다르면 기존 파일을 재사용하지 않는다. 외부 HTML은 [외부 HTML 저장](../04-external-html-download/reference.md), 본문 HTML은 [본문 HTML 저장](../05-internal-html-download/reference.md)에서 세부 검사 기준을 확인한다.
