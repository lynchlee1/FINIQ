# 공시분석 공통 사양 Reference

## 함께 쓰는 사양

### 작업공간

- 화면이 별도 경로를 받으면 입력과 결과 위치를 실행 요청에 명시하며 이름순 탐색으로 대신하지 않는다.
- 별도 경로를 사용해도 단계별 파일명과 상대 배치는 바꾸지 않는다. `06-sections`의 상대 배치는 `<mode>/<YYYY>/<acpt_no>.html`이다.
- 실행 중 실제 경로는 API 응답에 포함할 수 있지만 단계 결과 JSON에는 절대 디렉터리를 저장하지 않는다.
- 설정 조회와 일부 단계 자동화는 실제로 사용하는 단계 경로만 해석한다. 사용하지 않는 단계의 손상된 연결은 연결 상태 검사에는 오류로 남기되 다른 단계의 설정 조회나 실행을 막지 않는다.

### 비동기 작업

- `04-external-html-download`와 `05-internal-html-download` 취소는 이미 저장한 파일을 남기고 취소 상태를 돌려준다.
- worker 수는 양의 정수여야 한다. 기능 문서가 다른 기본값을 밝히면 그 값을 따른다.
- 실행 중인 작업 snapshot은 서버 기준 전체 경과시간과 마지막 상태·로그 갱신 뒤 경과시간을 제공한다.
- 상태 조회가 정상인 동안 10초 이상 새 로그가 없으면 화면은 작업 중단으로 단정하지 않고 무진행 시간을 표시한다.

### 기존 데이터 검토

- 번호가 붙은 01~07 화면은 페이지 진입이나 입력 변경만으로 기존 데이터 검사를 시작하지 않는다.
- 사용자가 `검사하기` 또는 해당 실행 동작을 눌렀을 때만 현재 입력에 대한 검사를 시작한다.
- 경로·조건·실행 설정이 바뀌면 이전 판정을 지우고, 늦게 도착한 이전 입력의 응답을 새 입력의 근거로 사용하지 않는다.
- 검사 결과를 받으면 같은 컨트롤에 `정상` 또는 `사용 불가` 판정을 표시하고, 해당 판정을 누르면 같은 입력을 다시 검사한다.
- 요청이나 비동기 작업이 검사 결과 없이 실패하면 오류를 표시하고, `사용 불가` 판정을 누르면 같은 입력을 다시 검사한다.

### 화면 표시

- 공시 화면은 빈 값을 `-`로 표시하고 숫자 `0`은 그대로 표시한다.
- 긴 파일 경로는 마지막 네 부분만 남기고 앞을 `.../`로 줄인다. 실제 경로와 저장 결과는 바꾸지 않는다.
- 진행 내역과 오류 예시는 화면별로 정한 개수만 보여 준다. 전체 개수와 성공·실패 판단은 줄이지 않는다.

### 진행 내역

- 공시 자동화와 06 목차 분리 화면은 우측 설정의 `진행 확인 간격 (건)`을 실행 요청에 전달한다. 공시 자동화는 같은 값을 03~07단계의 주기형 진행 로그에 사용하며, 07단계는 중간 저장을 사용하지 않는 실행에서도 이 간격마다 로그를 남긴다.

**공시 공통 상태** — 처음 10줄, 이후 최근 80줄

**공시 자동화** — 최근 30줄

**외부·본문 HTML 저장** — 최근 100줄

**목차 HTML 저장** — 최근 200줄
