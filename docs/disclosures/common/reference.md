# 공시분석 공통 사양 Reference

## 함께 쓰는 사양

### 작업공간

- 화면이 별도 경로를 받으면 입력과 결과 위치를 실행 요청에 명시하며 이름순 탐색으로 대신하지 않는다.
- 별도 경로를 사용해도 단계별 파일명과 상대 배치는 바꾸지 않는다.
- 실행 중 실제 경로는 API 응답에 포함할 수 있지만 단계 결과 JSON에는 절대 디렉터리를 저장하지 않는다.

### 비동기 작업

- `04-external-html-download`와 `05-internal-html-download` 취소는 이미 저장한 파일을 남기고 취소 상태를 돌려준다.
- worker 수는 양의 정수여야 한다. 기능 문서가 다른 기본값을 밝히면 그 값을 따른다.

### 화면 표시

- 공시 화면은 빈 값을 `-`로 표시하고 숫자 `0`은 그대로 표시한다.
- 긴 파일 경로는 마지막 네 부분만 남기고 앞을 `.../`로 줄인다. 실제 경로와 저장 결과는 바꾸지 않는다.
- 진행 내역과 오류 예시는 화면별로 정한 개수만 보여 준다. 전체 개수와 성공·실패 판단은 줄이지 않는다.

### 진행 내역

**공시 공통 상태** — 처음 10줄, 이후 최근 80줄

**공시 자동화** — 최근 30줄

**외부·본문 HTML 저장** — 최근 100줄

**목차 HTML 저장** — 최근 200줄
