# KIND 다운로드 경로

04·05단계는 직접 연결 하나와 `kind_proxy_urls`에 등록한 로컬 프록시를 함께 사용한다.

- 프록시는 중복되지 않은 `http://127.0.0.1:<port>` 또는 `http://localhost:<port>` 형식이어야 하며 현재 CPU 개수보다 하나 적은 수까지 등록할 수 있다.
- 프록시가 없으면 직접 연결만 사용한다. 원격 프록시와 인증정보가 포함된 URL은 허용하지 않는다.
- 실제 경로 수는 대상 수와 `max_workers`를 넘지 않는다. worker는 경로별로 나누되 합계가 `max_workers`와 같아야 한다.
- 각 경로는 별도 HTTP 세션과 요청 제한 상태를 유지한다. 모든 연도의 대상을 한 실행에서 처리해 연도 경계에서 제한을 초기화하지 않는다.
