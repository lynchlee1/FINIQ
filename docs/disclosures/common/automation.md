# 공시 자동화

선택한 1~7단계를 번호 순서대로 실행한다.

- 단계가 끝나면 실행 상태에 완료 기록을 남긴다.
- 각 단계는 세부 페이지와 같은 실행 함수와 공식 입출력 경로를 사용한다. 자동화 전용 단계 산출물이나 별도 처리 규칙은 두지 않는다.
- 03단계는 프리셋 원본의 완료·중단 결과와 검사 완료 위치를 다음 실행 입력으로 전달한다.
- 03단계 결과가 비어 있으면 `조건에 맞는 공시 없음`으로 정상 종료하고 04 이후 단계는 건너뛴다.
- 자동화는 정정 이력을 포함한 전체 공시를 다음 단계로 넘기기 위해 `최종보고서만` 옵션을 허용하지 않는다.
