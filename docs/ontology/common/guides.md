# Ontology 공통 사양

## 목적

여러 Ontology 화면이 공시 결과와 주가 자료를 찾아 분석 입력으로 사용한다.

## 핵심 기능

### 회사 자료 병합

여러 입력의 회사와 공시를 회사 ID와 접수번호 기준으로 합친다.

### 파일 이동

`storage-utility`에서 분석 자료를 지정한 저장 위치로 옮긴다.

### 병렬 처리

작업 수와 실행 환경에 맞춰 worker 수를 정하고 분석을 실행한다.

### 회사 검색

SQLite 공시 회사와 Quantiwise 가격 mapping의 회사를 하나의 검색 결과로 만든다.
