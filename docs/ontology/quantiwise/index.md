# Quantiwise

Excel 시트와 계정 mapping을 종목·날짜·계정별 Parquet으로 변환하고, 병합·중복 정리·시장 이력 통합 규칙을 다룬다. 화면은 backend가 반환한 출력 파일과 계정·날짜·회사 hash를 표시한다.
