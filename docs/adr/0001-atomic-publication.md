# ADR-0001: 단계 결과를 원자적으로 게시한다

- 상태: 승인
- 날짜: 2026-08-29

## 배경

공시 파이프라인은 한 단계의 결과를 다음 단계가 곧바로 읽는다. 새 결과를 만드는 도중 일부 파일만 정상 위치에 나타나면 후속 단계가 서로 다른 실행 세대의 파일을 함께 읽을 수 있다.

## 결정

단계 결과는 임시 위치에서 모두 만들고 검증한 뒤 하나의 세대로 게시한다. 게시 중 오류가 나면 기존 결과를 복원한다. 게시가 확정된 뒤 백업이나 임시 파일 정리만 실패한 경우에는 새 결과를 유지하고 정리 경고를 남긴다.

## 검토한 대안

- 파일을 만드는 순서대로 정상 위치에 저장한다.
- 실패한 파일만 제거하고 나머지 새 결과를 남긴다.

두 방식 모두 후속 단계에 부분 결과를 노출하거나, 한 실행의 결과인지 판별하기 어렵게 만든다.

## 영향

- 후속 단계는 정상 위치의 결과를 완성된 한 세대로 볼 수 있다.
- 게시 전 검증, 백업, 복원 절차가 필요하다.
- 대용량 작업은 새 결과와 기존 결과를 잠시 함께 보관할 공간이 필요하다.

현재 세부 동작은 [공시 처리 공통 계약](../disclosures/common/index.md)과 각 단계 문서가 소유한다.
