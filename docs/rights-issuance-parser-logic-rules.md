# 유무상증자 파서 로직 규칙

작성일: 2026-07-06
최종 업데이트: 2026-07-07

## 결론

유무상증자 HTML 파싱 워크플로우는 주변 메타데이터 파일의 공시 제목을 파서에
주입한다. 증자 유형은 이 주입 제목만으로 판정한다.

파서는 HTML 본문 표에서 유상증자와 무상증자에 공통으로 쓰이는 필드를 먼저 만든다.
이후 증자 유형에 따라 `유상증자`, `무상증자` 상세 객체를 만든다. 유무상증자 공시는
유상 섹션과 무상 섹션을 나누어 두 상세 객체를 모두 만든다.

워크플로우 단계:

1. `filtered.json`, `compressed-external-html.json`, 다운로드 manifest를 읽어
   `acpt_no` 기준 메타데이터 index를 만든다.
2. 주변 파일의 제목을 파서에 주입한다.
3. 파서는 주입 제목으로 증자 유형을 정한다.
4. HTML 본문 표에서 공통 추출 필드와 상세 객체를 만든다.
5. 추출 결과에 필드별 상태, 경고 메시지, 합계 검증 결과를 붙인다.
6. 전체 HTML 파싱 작업에서 주변 파일을 찾을 수 있으면 회사명, 상장구분, 정정공시
   묶음 정보를 보강한다.

책임 경계:

- `utils.py`: 기본 출력값 생성, 주입 제목 반영, 증자 유형 판정, 추출 대상 표 선별을
  담당한다.
- `extractor.py`: HTML 테이블/행/라벨을 기준으로 원천을 찾고 필드 값을 추출한다.
  필드별 원천 라벨, 표 조건, 합계 검증 규칙은 추출 규칙이므로 여기 둔다.
- `models.py`: 최종 유무상증자 출력 필드 이름을 정의한다.
- `__init__.py`: context 생성, extractor 호출, 출력 필드 조립, 경고 병합을 순서대로
  연결한다.

## 제목과 타입 판정

증자 유형 판정은 주입 제목만 사용한다. HTML 본문 제목, `증자방식` 행, 섹션
라벨은 판정에 쓰지 않는다.

판정 순서:

| 제목 문구 | 내부 타입 | 출력 `증자유형` |
| --- | --- | --- |
| `유무상증자` | `mixed` | `유무상증자` |
| `무상증자` | `bonus` | `무상증자` |
| `유상증자` | `paid` | `유상증자` |
| 위 문구 없음 | `unknown` | `unknown` |

메모:

- `유무상증자`를 먼저 확인한다. 이 순서가 아니면 `무상증자` 문구에 먼저 걸릴 수 있다.
- 주입 제목이 없거나 제목에 위 문구가 없으면 `unknown`으로 남긴다.
- `unknown`이어도 필드 추출은 계속한다.

## 출력 필드

### 워크플로우 메타데이터

이 필드들은 HTML 본문 표에서 직접 추출하는 증자 조건이 아니라, 전체 HTML 파싱
워크플로우가 주변 파일을 찾을 수 있을 때 보강하는 값이다.

| 필드 | 출처 | 기본값 |
| --- | --- | --- |
| `correction_families` | `filtered.json`의 공시 행을 기준으로 만든 원공시/정정공시 묶음 | `{}` |
| `rcept_no` | KIND HTML 워크플로우에서는 사용하지 않음 | `null` |
| `기업명(발행사)` | 다운로드 manifest, `filtered.json`, `compressed-external-html.json` | `null` |
| `상장구분` | 다운로드 manifest, `filtered.json`, `compressed-external-html.json` | `null` |

메모:

- KIND HTML 워크플로우의 기준 식별자는 `acpt_no`다.
- KIND HTML 워크플로우는 DART `rcept_no`를 만들거나 보강하지 않는다.

### 저장 JSON 공통 필드

이 필드들은 `parsed-rights_issuance.json`의 `records` 항목에 저장된다.

| 필드 | 값 |
| --- | --- |
| `acpt_no` | 확장자를 뺀 파일명에서 `_` 앞에 있는 숫자 부분. 숫자로 시작하지 않으면 빈 문자열 |
| `source_file` | 입력 HTML 파일의 절대 경로 |
| `mode` | `rights_issuance` |
| `title` | 파서 호출자가 주입한 제목. 단독 parser 호출에서 `title` 인자를 생략하면 HTML 제목이 출력 메타데이터로 남을 수 있음 |

메모:

- `title` 필드는 출력용 메타데이터다.
- `source_file`은 파싱한 HTML 파일 경로이며 HTML 원문 내용 자체를 보존하지 않는다.

### 파서 내부 원문 구조 필드

이 필드들은 유무상증자 파서가 필드 추출에 사용하지만, 웹 파싱 저장 단계에서
`records`에 남기지 않는다.

| 필드 | 값 | 저장 여부 |
| --- | --- | --- |
| `raw_tables` | HTML의 모든 표를 행/셀 구조로 정리한 값 | 저장하지 않음 |
| `raw_rows` | 모든 표의 행을 한 목록으로 합친 값 | 저장하지 않음 |

메모:

- `raw_tables`와 `raw_rows`는 `parse_rights_issuance()`의 직접 반환값에는 포함될 수
  있지만, `parse_disclosure_html_payload()`가 저장 JSON을 만들 때 제거한다.
- 추출 대상 표는 유무상증자 본문 필드 라벨, 유상/무상 섹션 표시, 제3자배정 대상자
  헤더로 고른다.
- 실제 증자 필드 추출은 추출 대상 표의 행을 기준으로 수행한다.

### 공통 추출 필드

아래 필드들은 증자 유형과 관계없이 최상위 record에 같은 이름으로 출력된다. 다만
필드의 의미와 누락 상태는 `유상증자`, `무상증자`, `유무상증자`, `unknown`에 따라
다르다.

#### 전체 타입 공통

| 필드 | 읽는 위치 | 없을 때 |
| --- | --- | --- |
| `증자유형` | 주입 제목의 `유무상증자`, `무상증자`, `유상증자` 문구 | 강한 경고 |
| `신주의 종류와 수` | `신주의 종류와 수` 행의 주식 종류별 정수 | 강한 경고 또는 0주 상태 |
| `증자 전 발행주식총수` | `증자전 발행주식총수` 행의 주식 종류별 정수 | 강한 경고 또는 0주 상태 |
| `신주권교부예정일` | `신주권교부예정일` 행의 마지막 값 | 강한 경고 |
| `상장예정일` | `신주의 상장 예정일` 행의 마지막 값 | 강한 경고 |

#### 유상증자

유상증자에서는 자금 조달과 납입 조건을 추출한다.

| 필드 | 읽는 위치 | 없을 때 |
| --- | --- | --- |
| `발행목적` | `자금조달의 목적` 행의 목적명과 금액 | 강한 경고 또는 0원 상태 |
| `발행가액` | `신주 발행가액` 행의 주식 종류별 정수 | 강한 경고 |
| `기준주가` | `기준주가` 행의 주식 종류별 정수 | 강한 경고 |
| `증자방식` | `증자방식` 행의 마지막 값 | 강한 경고 |
| `납입일` | `납입일` 행의 마지막 값 | 강한 경고 |
| `발행대상자` | 첫 logical row에 `제3자배정 대상자`와 `배정주식수`가 있는 표 | 제3자배정이면 강한 경고. 그 외에는 상태 없음 또는 빈 표 상태 |

#### 무상증자

무상증자에서는 자금 납입이 없으므로 유상증자 전용 필드는 해당 없음으로 처리한다.

| 필드 | 처리 |
| --- | --- |
| `발행목적` | 원천이 없으면 `not_applicable` |
| `발행가액` | 원천이 없으면 `not_applicable` |
| `기준주가` | 원천이 없으면 `not_applicable` |
| `납입일` | 원천이 없으면 `not_applicable` |
| `증자방식` | 원천이 없으면 제목 판정값인 `무상증자`로 보완 |
| `발행대상자` | 보통 사용하지 않는다. 표가 없고 제3자배정 누락 조건도 아니면 상태를 만들지 않는다. |

#### 유무상증자

유무상증자에서는 같은 HTML 안의 유상 섹션과 무상 섹션을 나누어 읽는다.

| 출력 위치 | 기준 |
| --- | --- |
| 최상위 공통 필드 | 전체 추출 대상 행 |
| `유상증자` 상세 객체 | 유상 섹션 행 |
| `무상증자` 상세 객체 | 무상 섹션 행 |

최상위 `발행목적`, `발행가액`, `기준주가`, `증자방식`, `납입일`, `발행대상자`는
유상증자 조건을 설명하는 값으로 본다. 무상증자 조건은 `무상증자` 상세 객체에서
별도로 확인한다.

#### 기타 또는 unknown

주입 제목에서 증자 유형을 판정하지 못하면 `증자유형`은 `unknown`으로 남긴다.
이 경우에도 필드 추출은 계속하지만 `유상증자`, `무상증자` 상세 객체는 만들지
않는다. 증자 유형 판정 실패는 강한 경고로 기록한다.

세부 규칙:

- 주식 계열 필드는 항상 `보통주식`, `기타주식` 순서로 반환한다.
- `기타주식`은 `기타주식`, `기타주`, `우선주식`, `우선주`, `종류주식`, `종류주`를
  `기타주식` 출력 라벨로 묶는다.
- `신주의 상장 예정일`은 공백을 제거해 `신주의 상장예정일`도 동일 라벨로 인식한다.
- `발행목적`은 시설자금, 영업양수자금, 운영자금, 채무상환자금, 타법인 증권 취득자금,
  기타자금 순서로 읽는다.
- `발행목적` 금액이 0인 목적은 결과 목록에서 제외한다.
- 무상증자에서 `발행목적`, `발행가액`, `기준주가`, `납입일`의 원천이 없으면
  `not_applicable` 상태로 기록한다.
- `증자방식` 원천이 없고 증자 유형이 무상증자이면 `무상증자`를 출력값으로 사용한다.

### 발행대상자 표 규칙

발행대상자는 제3자배정 표에서 대상자명과 배정주식수를 읽는다.

- 첫 logical row에 `제3자배정 대상자`와 `배정주식수`가 모두 있어야 발행대상자 표로
  인정한다.
- 후보 표가 여러 개이면 `신주의 종류와 수` 합계와 배정주식수 합계가 일치하는 표를
  먼저 사용한다.
- `증자방식`에 `제3자배정`이 있고 발행대상자 표가 없으면 강한 경고를 남긴다.
- 제목에 `종속회사`가 있으면 제3자배정 표 누락 경고를 만들지 않는다.

| 상황 | 출력 `발행대상자` | 상태 | 경고 |
| --- | --- | --- | --- |
| 발행대상자 표를 찾지 못함 | `[]` | 제3자배정 누락 경고가 나면 `source_not_found`, 아니면 상태 없음 | `증자방식`에 `제3자배정`이 있고 제목에 `종속회사`가 없으면 강한 경고 |
| 표를 찾았지만 보존할 대상자 행이 없음 | `[]` | `source_found_empty` | 없음 |
| 표를 찾았고 일부 행의 대상자명이 `-`임 | `-` 행은 제외하고 나머지 `[대상자명, 배정주식수]` 기록 | `parsed` | 합계가 맞지 않으면 약한 경고 |
| 표를 찾았고 일부 행의 배정주식수만 `-`임 | 해당 행은 제외하고 나머지 숫자 행만 기록 | 남은 대상자가 있으면 `parsed`, 없으면 `source_found_empty` | 합계가 맞지 않으면 약한 경고 |
| 표를 찾았고 모든 대상자명이 `-`이며 배정주식수가 없음 | `[["-", 0]]` | `explicit_zero` | 신주 합계와 맞지 않으면 약한 경고 |
| 표를 찾았고 대상자명과 배정주식수가 있음 | `[대상자명, 배정주식수]` 목록 | `parsed` | 합계가 맞지 않으면 약한 경고 |

`발행대상자` 표가 아예 없고 제3자배정 누락 경고 조건에도 걸리지 않으면 현재 로직은
`field_parse_status["발행대상자"]`를 따로 만들지 않는다.

총계 행 제거 규칙:

- 마지막 행 이름을 공백으로 나눈 토큰 중 하나가 `계`, `합계`, `소계`, `총계`이면
  총계 후보로 본다.
- 대상자 합계가 신주 합계의 2배이고 마지막 행 금액이 신주 합계이면 마지막 행을
  제거한다.

## 상세 객체

`유상증자`와 `무상증자` 상세 객체는 공통 추출 필드와 섹션별 추가 필드를 묶은 값이다.

| 내부 타입 | `유상증자` | `무상증자` | 기준 행 |
| --- | --- | --- | --- |
| `paid` | 생성 | `null` | 전체 추출 대상 행 |
| `bonus` | `null` | 생성 | 전체 추출 대상 행 |
| `mixed` | 생성 | 생성 | 유상 섹션 행과 무상 섹션 행 |
| `unknown` | `null` | `null` | 상세 객체를 만들지 않음 |

`mixed` 섹션 분리 규칙:

- `무상증자`를 포함하고 `유무상증자`를 포함하지 않는 첫 행을 무상증자 시작 행으로 본다.
- 무상증자 시작 행 앞은 유상 섹션, 시작 행부터 끝까지는 무상 섹션이다.
- 무상증자 시작 행을 찾지 못하면 유상 섹션은 전체 추출 대상 행, 무상 섹션은 빈 목록이다.

상세 객체 필드:

| 객체 | 필드 | 값 |
| --- | --- | --- |
| `유상증자` | `신주의 종류와 수`, `증자 전 발행주식총수`, `발행목적`, `발행가액`, `증자방식`, `납입일`, `신주권교부예정일`, `상장예정일`, `발행대상자` | 공통 추출 필드 값 |
| `유상증자` | `신주배정기준일` | 유상 섹션의 `신주배정기준일` 행 마지막 값 |
| `유상증자` | `1주당 신주배정주식수` | 유상 섹션의 주식 종류별 배정비율 |
| `무상증자` | `신주의 종류와 수`, `증자 전 발행주식총수` | 무상 섹션의 주식 종류별 정수 |
| `무상증자` | `신주배정기준일`, `신주권교부예정일`, `상장예정일` | 무상 섹션의 해당 행 마지막 값 |
| `무상증자` | `1주당 신주배정주식수` | 무상 섹션의 주식 종류별 배정비율 |

메모:

- 상세 객체 내부 필드는 별도 상태 코드를 만들지 않는다.
- 배정비율 행에서 주식 라벨별 값을 찾지 못하면 마지막 값을 `보통주식` 값으로 사용한다.

## 경고와 상태

### 상태 코드

| 코드 | 의미 |
| --- | --- |
| `parsed` | 값을 찾았다. |
| `explicit_zero` | 원문에서 0 또는 대시를 읽어 0으로 해석했다. |
| `source_not_found` | 정해진 위치에서 값을 찾지 못했다. |
| `not_applicable` | 증자 유형상 해당 필드가 없다. |
| `source_found_empty` | 표는 찾았지만 보존할 값이 없다. |

### 경고 출력 필드

| 출력 필드 | 들어가는 내용 |
| --- | --- |
| `field_parse_status` | 필드별 상태 코드 |
| `parse_warnings` | 모든 경고를 한 곳에 모은 목록 |
| `weak_warning` | 추출은 됐지만 값 사이의 관계가 어긋난 경우 |
| `medium_warning` | `신주의 종류와 수`에서 0이 아닌 주식 종류가 둘 이상인 경우 |
| `strong_warning` | 증자 유형을 판정하지 못했거나 정해진 위치에서 필드 값을 찾지 못한 경우 |

검증 규칙:

- `발행대상자` 합계와 `신주의 종류와 수` 합계가 다르면 약한 경고를 남긴다.
- `신주의 종류와 수`와 `기준주가`를 곱한 값이 `발행목적` 합계와 10원 이상 다르면
  약한 경고를 남긴다.
- `신주의 종류와 수`가 명시적으로 모두 0이면 약한 경고를 남긴다.
- `신주의 종류와 수`에서 0이 아닌 주식 종류가 둘 이상이면 중간 경고를 남긴다.
