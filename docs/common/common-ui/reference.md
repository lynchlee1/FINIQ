# 공통 화면 사양

공시분석과 Ontology 화면이 함께 따르는 작업 복구, 결과 표시, 설정 저장 규칙을 설명한다.

## 비동기 작업 복구

- 브라우저에 작업 ID가 남아 있으면 화면을 다시 열었을 때 같은 작업의 상태를 확인한다.
- 상태 조회가 `404`를 반환하면 저장한 작업 ID를 지운다.
- 결과 본문, 실패 이유나 완료 결과를 읽지 못하면 성공으로 처리하지 않는다.
- 서버가 오류 알림을 보내거나 결과 없이 전송을 끝내면 실패 처리한다.
- 서버가 실패 이유를 보내지 않으면 `Job failed`를 표시한다.
- 브라우저 저장 공간을 읽지 못하면 저장된 작업이 없는 것으로 본다. 저장 공간을 바꾸지 못해도 현재 작업 확인은 계속한다.

## 화면 결과 표시

- 긴 파일 경로는 마지막 네 부분만 남기고 앞을 `.../`로 줄인다. 실제 경로와 저장 결과는 바꾸지 않는다.
- 진행 내역과 오류 예시는 화면별로 정한 개수만 보여 준다. 전체 개수와 성공·실패 판단은 줄이지 않는다.
- 빈 값은 화면 문맥에 따라 `-` 또는 `N/A`로 표시한다.
- 숫자 `0`은 빈 값으로 바꾸지 않는다.

## 설정 저장

- 설정을 저장하지 못해도 현재 입력값은 화면에서 지우지 않는다.
- 화면에 값이 남아 있어도 서버 설정은 바뀌지 않았을 수 있다.
