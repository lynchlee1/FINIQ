# 우측 도크 용어

| 대상 | 용어 |
| --- | --- |
| 실행 상태 패널 | 실행 현황 |
| 메시지 패널 | 알림 |
| 설정 패널 | 설정 |
| 알림 비우기 | 지우기 |
| 병렬 처리 수 | 워커 수 |
| 요청 제한 | 타임아웃 (초) / 요청 간격 (초) |
| 진행 갱신 | 진행 확인 간격 (건) |
| 처리 한도 | 최대 처리 건수 / 페이지 크기 |
| 병렬 방식 | 병렬 처리 방식 |
| 병렬 방식 옵션 | 연도별 병렬 / 한 연도 내 병렬 |
| 작업 보관 | 작업 기록 보관 시간 (분) |
| 실행 시간 | 작업 경과 |
| 네트워크 처리량 | 다운로드 속도 |
| 상태 갱신 여부 | 진행 확인 |

알림은 도크 색상만 바꾸고 패널을 자동으로 열지 않는다.
