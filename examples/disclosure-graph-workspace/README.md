# 공시 관계 그래프 예시 작업공간

공시 관계 그래프 화면의 `작업공간 디렉토리`에서 이 폴더를 선택하고 `저장 결과 불러오기`를 누른다.

이 예시는 화면과 저장 형식을 검증하기 위한 테스트 데이터다.

- node는 Company, Person, Organization entity만 포함한다.
- 개별 공시, 발행 event, 증권과 의안은 node로 만들지 않는다.
- 공시 제목, 접수번호와 추출 상세는 edge의 `properties`에서 확인한다.
- 실제 공시 워크플로우 입력으로 다시 생성하는 예시가 아니라 저장 결과 조회용 fixture다.
