# Guide 안내 문장 윤문 결과

공시 자동화 03단계에서 조건검색 워크플로우를 만들고 실행한다. 조회·저장 흐름은 동작 문서, 중단된 검색을 잇거나 실행을 멈추는 조건은 예외 문서에서 확인한다.

공시 자동화 04단계에서 외부 HTML 다운로드 경로를 정하고 실행한다. 저장·검증 흐름은 동작 문서, 재시도·재사용·중단 조건은 예외 문서에서 확인한다.

공시 자동화 05단계에서 본문 HTML 저장을 실행한다. 다운로드 대상과 저장 흐름은 동작 문서, 기존 파일 재사용과 중단 조건은 예외 문서에서 확인한다.

공시 자동화 06단계에서 저장할 목차를 확인하고 본문 범위를 나눈다. 분리·선택 흐름은 동작 문서, 입력 오류와 중단 조건은 예외 문서에서 확인한다.

공시 자동화 07단계에서 변환 유형을 고르고 목차 HTML을 구조화된 결과로 바꾼다. 저장 구조와 추출 규칙은 동작 문서, 복구와 중단 조건은 예외 문서에서 확인한다.
