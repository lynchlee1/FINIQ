# 기존 데이터 검토 안내 문구

## 01 공시내역 다운로드

- 경로를 선택하고 검사하기를 누르면 기존 데이터와 메타데이터를 확인합니다.
- 검사하기를 누르면 저장된 메타데이터와 현재 설정, 파일 구성, KIND 건수를 차례로 확인합니다.
- 기존 데이터에 문제가 있습니다.
- 기존 데이터에 이어서 저장해도 됩니다.
- 검사하기를 누르면 저장된 메타데이터를 확인합니다.
- 검사하기를 누르면 페이지 번호가 빠짐없이 이어지는지, 파일 구성이 올바른지 확인합니다.
- 페이지 번호와 파일 구성을 검사하고 있습니다.
- 문제가 있는 파일 수를 표시합니다.
- 앞 단계가 끝나면 로컬 건수와 KIND의 현재 건수를 비교합니다.
- 로컬 건수가 KIND의 현재 건수와 다른 범위 수를 표시합니다.
- 실행 전에 저장된 메타데이터와 현재 설정, 파일 구성, KIND 건수를 차례로 확인합니다.

## 02 공시내역 변환

- 입력 경로와 결과 경로를 선택한 다음 기존 SQLite 변환 결과를 검사하세요.
- 다운로드한 원본 데이터와 변환 기록, 연도별 SQLite 파일의 내용이 서로 일치하는지 확인합니다.
- 기존 변환 데이터를 그대로 사용해도 됩니다.
- 기존 변환 데이터에 문제가 있습니다.
- 원본 데이터에서 중복을 제외한 내용이 몇 개의 연도별 SQLite 파일에 저장되어 있는지 표시합니다.
- 원본 데이터의 페이지별 건수, 변환 기록의 요약, 연도별 SQLite 파일의 행 수가 일치하는지 확인합니다.
- 실행 전에 다운로드한 원본 데이터와 변환 기록, 연도별 SQLite 파일의 내용이 서로 일치하는지 확인합니다.
- 다운로드한 원본 데이터와 변환 기록, 연도별 SQLite 파일의 내용이 모두 일치합니다.
- 다운로드한 원본 데이터의 건수와 변환 기록의 요약이 다릅니다.
- 다운로드한 원본 데이터와 변환 기록에 적힌 페이지별 건수가 다릅니다.
- 다운로드한 원본 데이터의 연도별 건수와 SQLite 파일 구성이 다릅니다.

## 03 공시내역 필터링

- 작업공간 디렉토리를 선택한 다음 조건검색 폴더를 모두 검사하세요.
- 각 폴더의 저장 설정과 처리 단계를 확인하고 결과에 문제가 없는지 검사합니다.
- 조건검색 폴더에 문제가 있습니다.
- 조건검색 폴더의 저장 설정과 처리 단계, 결과를 모두 확인했습니다.
- 검사하기를 누르면 현재 선택한 필터와 관계없이 조건검색 폴더를 모두 확인합니다.
- 실행 전에 저장된 조건검색 설정과 처리 단계를 확인하고 결과에 문제가 없는지 검사합니다.

## 04·05 공시원문 저장

- 입력 경로와 결과 경로를 선택한 다음 검사하기를 누르세요.
- 현재 대상과 저장 파일을 비교하고 기준 해시를 확인합니다.
- 기존 원문 데이터에 문제가 있습니다.
- 기존 원문 데이터를 그대로 사용해도 됩니다.
- 전체 대상 중 저장된 건수와 새로 저장해야 할 건수를 표시합니다.
- 실행 전에 현재 대상과 저장 파일을 비교하고 기준 해시를 확인합니다.

## 06 공시원문 목차 분리

- 내부 HTML 데이터 경로를 선택한 다음 기존 원문의 목차 구성을 검사하세요.

## 07 공시원문 변환

- 입력 경로와 결과 경로를 선택하세요.
- 경로를 선택한 다음 현재 설정으로 변환 결과를 다시 계산해 저장된 결과와 비교하세요.
- 기존 변환 결과를 그대로 사용해도 됩니다.
- 기존 변환 결과에 문제가 있습니다.
- 전체 대상 중 변환한 파일과 실패한 파일 수를 표시합니다.
- 변환 과정에서 현재 설정으로 입력 HTML을 처리한 내용과 저장된 결과를 확인했습니다.
- 현재 설정으로 다시 변환한 내용이 저장된 결과와 모두 일치합니다.
